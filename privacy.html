Privacy Policy

Effective October 6, 2026 · Wolf Grey Context

The owner and operator of the Wolf Grey Context internal project ("Provider," "we," or "us") provides the Wolf Grey Context application ("Application"). This policy describes the current local, owner-operated version. Wolf Grey Context is the application name, not a separately formed legal entity. Current functionality and actual data flows determine the information processed.

1. Information processed

The Application processes integration credentials and OAuth authorization tokens; QuickBooks company identifiers and company information; account and class lists; requested Profit and Loss and Balance Sheet reports; and supported financial exports you import locally. It creates searchable records, source references, report metadata, comparison differences and regression artifacts. Financial reports or imported records can contain personal information about customers, vendors or other people. The current API connector does not separately retrieve invoices, customer or vendor lists, or detailed journal entries.

2. How information is used

Information is used to authorize connections, retrieve records you request, organize local evidence, reproduce accounting calculations, compare reports, and investigate errors or differences. Retrieved reports are evidence, not automatic approval of accounting conclusions. You should only connect accounts and provide records you are authorized to access.

3. Storage and service providers

The current Application stores credentials, report snapshots, searchable records and review artifacts on the machine where it runs. It does not operate a hosted financial-data store, automatic cloud backup or customer synchronization service. QuickBooks authorization and report retrieval communicate with Intuit over HTTPS and are subject to Intuit's terms and privacy practices.

These public policy pages are hosted separately from the Application's private code and financial records. When published using GitHub Pages, GitHub receives ordinary website requests under its own privacy statement. The pages do not include application financial data, analytics scripts or forms.

4. AI assistants and optional sharing

The current Application code does not make automatic calls to the OpenAI API or other AI model APIs. An authorized operator may separately use a cloud AI assistant, including OpenAI's Codex or ChatGPT, to inspect relevant records or search results for a requested task. Information shown to that assistant is transmitted to its provider for processing; keeping a source file on your computer does not make that processing local. Credentials and authorization tokens must not be included in assistant inputs.

Each selected service and account has its own settings and data practices. OpenAI's API-specific practices are described in its API data controls documentation; those API rules do not establish the settings or retention of a separately used assistant account. The Application does not promise zero retention or model-training exclusions for every assistant service. Future built-in AI processing requires an updated description of its actual data flows.

5. Other sharing

The current Application has no advertising, sale-of-data or advertising-tracking functionality. Its implemented external data flow is the authorized Intuit integration; any additional AI sharing is separately chosen by the operator as described above. Information you send for support or legal requests may be used to respond, and may be disclosed when required by applicable law. Public policy-page hosting does not make local financial records public.

6. Security

The connector sends requests to Intuit over HTTPS, stores credentials separately from searchable financial snapshots, and uses restrictive local file permissions for credentials and generated records. Credential updates are written atomically, connection operations use a local file lock, and OAuth authorization uses a random state value that expires. Private storage is excluded from this project's Git publication.

The current Application does not encrypt its stored records or credentials itself and does not implement customer account isolation or a managed security-monitoring service. Protection also depends on the operator's operating-system account, device security, disk encryption and backup choices. Those protections are not supplied merely by installing the Application. No system can be guaranteed completely secure.

7. Retention and deletion

Local records and credentials are retained until the authorized operator deletes them. The current Application has no automatic expiration schedule or built-in deletion service. It preserves dated report snapshots and frozen comparison references instead of replacing them silently.

To stop future QuickBooks access, revoke the connection through Intuit and stop using the connector. Separately remove local connection files and the report snapshots, searchable records, regression references and outputs you intend to delete. Disconnecting does not delete those existing records. Copies you made elsewhere, operating-system backups, source exports and information already submitted to an external assistant must be handled separately through their applicable controls. Provider does not remotely erase files from your device.

Contact us with questions or requests about information you supplied directly to Provider. We will identify the relevant copies and applicable options, accounting for records that must be retained under applicable law. Deleting a local copy does not guarantee deletion of external-service records.

8. Your choices

You choose whether to authorize a QuickBooks company, which supported reports to retrieve, which records to import and whether to share relevant content with a separate assistant. Use Intuit's controls to revoke access. Contact the address below to ask about access, correction or deletion; available rights and obligations depend on applicable law and who holds the records.

9. Changes and intended audience

The Application is intended for authorized business users and is not directed to children. We will update this policy and its effective date when practices change and provide additional notice when required by applicable law. Future hosted services, customer access controls, accounting writes or automatic AI processing must be described accurately before they are offered.
